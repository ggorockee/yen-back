# AdMob 스토어 연결 체크리스트 (출시 후)

AdMob 콘솔(woohalabs@gmail.com)에서 돌려받엔 앱 두 개 모두 아직 "검토 필요 / 광고 게재가 제한됨" 상태다. iOS는 App Store 연결까지 끝났고 앱 인증만 남았으며, Android는 스토어 미연결이다. 앱이 스토어에 **정식 공개된 뒤에만** 스토어 연결이 가능하므로, 각 플랫폼 출시 직후 아래 순서로 진행한다.

작성일: 2026-11-16 / 최종 확인: 2026-11-25 (App Store Connect, AdMob, Google Ads 콘솔)

## 1. 사전 확인 (출시 전에 끝내기)

- [x] 서버에 /app-ads.txt 추가 (PR #7 머지)
- [x] https://yen-back.woohalabs.com/app-ads.txt 가 200으로 응답하고 내용이 "google.com, pub-8516861197467665, DIRECT, f08c47fec0942fa0" 인지 확인
- [ ] Play Console 스토어 설정의 웹사이트가 https://yen-back.woohalabs.com 인지 확인
- [x] App Store Connect 앱 정보의 마케팅 URL(개발자 웹사이트)이 https://yen-back.woohalabs.com 인지 확인

## 2. Android 출시 후 (Play 프로덕션 공개 직후)

- [ ] Play 스토어에서 "돌려받엔" 또는 com.woohalabs.yenback 검색 시 앱이 보이는지 확인 (공개 후 수 시간 걸릴 수 있음)
- [ ] AdMob → 앱 → 돌려받엔 Android → "스토어 추가"
- [ ] Google Play 검색창에 com.woohalabs.yenback 입력 → 검색 결과에서 돌려받엔 선택 → 계속
- [ ] 패키지 이름 확인 단계에서 com.woohalabs.yenback 일치 확인 → 완료
- [ ] AdMob 앱 목록에서 스토어 열이 "Google Play"로 바뀌었는지 확인
- [ ] 승인 상태가 "검토 필요" → "준비됨"으로 바뀌는지 확인 (AdMob 검토는 보통 수일 소요)

## 4. app-ads.txt 확인 (스토어 연결 후 1~7일)

- [ ] 상태가 "app-ads.txt 파일을 찾아서 확인했습니다"인지 확인
- [ ] 2026-11-26 이후 앱 인증 화면에서 "업데이트 확인"을 다시 눌러 재검증

## 6. Google Ads 예산

세 앱(리뷰맵, 라익찍스, 돌려받엔) 합계 월 100,000원. 월 상한은 일 예산 × 30.4.

| 캠페인 | 일 예산 | 월 상한 | 상태 (2026-11-25) |
|---|---|---|---|
| 리뷰맵-안드로이드 | 820원 | 약 24,930원 | 운영 가능, 최근 7일 노출 1회 |
| 리뷰맵-iOS | 820원 | 약 24,930원 | 운영 가능, 최근 7일 노출 0회 |
| 돌려받엔-iOS | 986원 | 약 29,970원 | 게시 (2026-11-25), 운영 가능(학습 중) |
| 라익찍스 | 미정 | 잔여 약 20,170원 | 캠페인 없음 |

돌려받엔-iOS 설정: 앱 설치, 대한민국(현재 위치), 한국어, 설치 전환수 최대화(타겟 설치당비용 없음), 광고 제목 5개, 설명 5개, 이미지 6장(가로, 정사각형, 세로 × 2종). 동영상이 없어 광고 효력은 "나쁨"으로 표시된다.

- [x] 돌려받엔-iOS 앱 설치 캠페인 게시 (월 30,000원, 2026-11-25). 게시 전 Google Ads가 본인 인증을 요구하며 계정 소유자가 직접 인증해야 한다
- [x] Firebase 프로젝트 yen-back 생성, iOS 앱 등록, Google 애널리틱스 사용 (2026-11-25)
- [x] 애널리틱스와 Google Ads 계정 연결 (2026-11-25, 맞춤 광고용 공유와 Google Ads의 애널리틱스 변경 권한은 끔, 자동 태그는 기존 설정 유지)
- [x] Remote Config 템플릿 배포 (광고 on/off와 빈도, 앱 버전 관리)
- [ ] Firebase가 포함된 iOS 버전 배포
- [ ] 배포 후 first_open 이벤트가 들어오면 Google Ads 목표 → 전환에서 앱 다운로드 전환으로 가져오기. 그 전에는 Google Ads가 "앱 다운로드에 전환 추적을 설정하기 전에는 앱 캠페인이 제대로 작동하지 않습니다"라고 경고한다
- [ ] 라익찍스 예산 확정
- 참고: 오점너-안드로이드(500원/일)는 일시중지, "임시: 리뷰맵 안드로이드"(5,000원/일)는 미게시 초안. 초안을 게시하면 합계 예산을 넘는다.

### 예산과 실제 비용

| 질문 | 확인 결과 | 근거 |
|---|---|---|
| 예산만 설정하면 차감되는가 | 아니오. 실제로 게재돼 발생한 비용만 월별 후불로 청구 | Google Ads 도움말 10486637, 리뷰맵 캠페인의 청구 내역 |
| 노출만 돼도 비용이 나가는가 | 앱 설치 캠페인의 과금 단위는 공식 문서에서 명시를 찾지 못함. 이 계정에서는 노출 1회, 클릭 0회에 비용 0원 | 캠페인 보고서 2026-11-18~24 |
| 하루 최대 | 일 예산의 2배 | Google Ads 도움말 10486637, 캠페인 생성 화면 |
| 한 달 최대 | 일 예산의 30.4배 | Google Ads 도움말 10486637 |
| 지역 평균 설치당비용 | 755원 (Google Ads 캠페인 생성 화면 표시값) | 일 986원이면 하루 1건 안팎 |

예산을 늘려도 지금은 게재 자체가 거의 없어 비용이 늘지 않을 가능성이 있다. 설치 전환을 가져온 뒤 1~2주 게재량을 보고 증액을 판단한다. 총 100,000원 안에서 올릴 수 있는 최대는 돌려받엔-iOS 일 1,640원(월 약 49,860원)이며, 이 경우 라익찍스 몫은 남지 않는다.

## 문제 해결

| 증상 | 원인 | 조치 |
|---|---|---|
| 스토어 추가 검색에 앱이 안 나옴 | 공개 직후 색인 지연, 또는 테스트 트랙만 공개 | 전체 스토어 URL(앱 이름 포함)로 검색, 프로덕션 공개 여부 확인 후 수 시간 뒤 재시도 |
| app-ads.txt 행이 계속 안 보임 | 개발자 웹사이트 도메인 불일치, 서버 미배포 | 스토어 웹사이트 URL과 /app-ads.txt 응답 확인 |
| 승인 상태가 계속 "검토 필요" | AdMob 앱 검토 진행 중 | 수일 대기, 정책 센터에서 위반 사항 확인 |
| EU 사용자에게 광고가 거의 안 나옴 | 동의 거부 또는 UMP 미적용 버전 | PR #8(UMP 동의) 포함 버전인지 확인 |
